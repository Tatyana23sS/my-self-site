## Зачем нужна библиография?

Библиография — это список источников, которые вы использовали при написании работы. Она нужна для:
- **Подтверждения достоверности** ваших данных
- **Избежания плагиата** — вы показываете, какие идеи взяты у других авторов
- **Возможности проверить** ваши источники

## Основные элементы библиографической ссылки

| Элемент | Пример |
|---------|--------|
| Автор(ы) | Иванов И.И. |
| Название | «Методы машинного обучения» |
| Где опубликовано | Журнал «Информатика» |
| Год | 2024 |
| Номер выпуска | №5 |
| Страницы | С. 23–30 |
| DOI (если есть) | 10.1234/example |

## Библиографические стили

| Стиль | Где используется |
|-------|------------------|
| **ГОСТ Р 7.0.5-2008** | В России (курсовые, дипломы, ВАК) |
| **APA** | Психология, педагогика, США |
| **MLA** | Гуманитарные науки |
| **Chicago** | История, искусство |
| **IEEE** | Технические науки |

## Инструменты для работы с библиографией

### 1. Менеджеры ссылок (Reference Managers)

| Инструмент | Особенности |
|------------|-------------|
| **Mendeley** | Бесплатный, синхронизация, плагин для Word |
| **Zotero** | Бесплатный, открытый код, веб-интеграция |
| **EndNote** | Платный, мощный функционал |
| **JabRef** | Бесплатный, для BibTeX/LaTeX |

### 2. Генераторы библиографии
- **BibTeX** — для LaTeX
- **Cite This For Me** — онлайн-генератор
- **Google Scholar** может сгенерировать цитату (нажать на кавычки `“”` под статьёй)

## Как работает Mendeley

Mendeley позволяет:
1. **Добавлять PDF-статьи** в библиотеку
2. **Автоматически извлекать** метаданные (авторы, название и т.д.)
3. **Сортировать** по папкам и тегам
4. **Генерировать ссылки** и вставлять в Word/Google Docs
5. **Синхронизировать** между устройствами

**Pro tip:** Установите плагин Mendeley в Word — тогда добавление цитат станет моментальным.

## Советы для студентов

1. **Начинайте библиографию сразу** при написании работы
2. **Используйте DOI** (Digital Object Identifier) — постоянный идентификатор статьи
3. **Проверяйте ссылки по ГОСТ** перед сдачей
4. **Заведите ORCID** — это ваш уникальный ID в науке
