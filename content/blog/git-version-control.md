## Что такое Git?
Git — это распределённая система контроля версий, которая позволяет отслеживать изменения в коде и работать в команде.

## Основные команды

| Команда | Назначение |
|---------|-----------|
| `git init` | Создать новый репозиторий |
| `git add .` | Добавить все изменения |
| `git commit -m "message"` | Зафиксировать изменения |
| `git push` | Отправить на удалённый репозиторий |
| `git pull` | Получить изменения с сервера |

## Зачем это нужно?
- История изменений
- Возможность отката
- Совместная работа
- Хостинг проектов (GitHub)
