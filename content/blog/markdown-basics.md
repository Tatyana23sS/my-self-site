## Что такое Markdown?

**Markdown** — это лёгкий язык разметки, который позволяет писать форматированный текст в обычном текстовом редакторе, а затем преобразовывать его в HTML.

## Зачем нужен Markdown?

- Простой и понятный синтаксис
- Не нужны специальные программы
- Подходит для:
  - Документации
  - Блогов
  - README-файлов на GitHub
  - Сайтов на Hugo

## Основной синтаксис Markdown

| Элемент | Синтаксис | Результат |
|---------|-----------|-----------|
| Заголовок | `# Заголовок 1` | **Заголовок 1** |
| Жирный текст | `**текст**` | **текст** |
| Курсив | `*текст*` | *текст* |
| Список | `- пункт` | • пункт |
| Ссылка | `[текст](url)` | [текст](url) |
| Код | `` `код` `` | `код` |
